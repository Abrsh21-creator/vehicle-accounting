## 🎯 Typical Monthly Workflow

### Time Required: 5-10 minutes

```
1. Start App (10 seconds)
   npm run dev

2. Enter Month Name (10 seconds)
   e.g., "የካቲት 2016" or "January 2024"

3. Input Financial Data (2 minutes)
   • Gross income from the vehicle
   • Bank payment for the month
   • Maintenance/fuel expenses
   • Salaries for Amsalu and Smeneh
   • Equb contributions

4. Review Results (2 minutes)
   • See each person's net payout
   • Check color coding (green=profit, red=debt)
   • Click "Show Breakdown" for details

5. Verify Calculations (1 minute)
   • Review step-by-step math
   • Ensure everything looks correct

6. Save & Print (2 minutes)
   • Click "Save Month & Carry Over"
   • Click "Print" and save as PDF
   • Store PDF safely

7. Done! (10 seconds)
   • Press Ctrl+C to stop app
```


```

• Clearing browser cache = losing history
• Always print important months to PDF
• That's why "Print" button is there!
```
