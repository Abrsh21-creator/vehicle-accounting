**Cons**:

- Only works on same network

## 🎯 Usage Workflow

### Monthly Routine (5-10 minutes)
```
1. Start app:           npm run dev
2. Enter month name:    e.g., "January 2024"
3. Input finances:      Income, expenses, salaries
4. Review results:      Check all three payouts
5. Verify breakdown:    Click "Show Breakdown"
6. Save month:          Click "Save Month & Carry Over"
7. Print record:        Click "Print" → Save as PDF
8. Close app:           Ctrl+C in terminal
```

## 🆘 Troubleshooting

### App won't start
```bash
Problem: npm run dev fails
Solution: 
  1. cd vehicle-accounting-dashboard
  2. npm install
  3. npm run dev
```

### Calculations wrong
```
Problem: Results don't match expectations
Solution:
  1. Click "Show Breakdown"
  2. Verify all inputs are correct numbers
  3. Check for verification warning
  4. Review CALCULATION_EXAMPLES.md
```

### History disappeared
```
Problem: Saved months missing
Solution:
  - Check if browser cache was cleared
  - History is permanently lost if cache cleared
  - Always print important months to PDF
```

### Print layout broken
```
Problem: Print doesn't look right
Solution:
  - Use Chrome or Edge browser
  - Set print margins to default
  - Select "Portrait" orientation
  - Ensure "Background graphics" is enabled
```
